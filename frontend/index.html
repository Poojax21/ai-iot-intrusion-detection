Two-Stage Hybrid Inference Pipeline

Stage 1: Cheap Behavioral Gate (Every Flow)
Runs an unsupervised Isolation Forest trained strictly on benign baseline traffic, paired with a high-throughput Random Forest binary gate tuned to a hard False Positive Rate ceiling.

Stage 2: Multiclass & Open-Set EVT (Flagged Flows)
Flagged traffic enters a 4-way classifier and an Extreme Value Theory (EVT) distance model. Flows that deviate from known centroids are declared Zero-day / Out-of-Distribution rather than misclassified.

Stage 3: Temporal LSTM & Graph Topology
Tracks per-device causal packet histories and communication graph degree anomalies.
