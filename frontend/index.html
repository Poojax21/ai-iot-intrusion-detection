🧠 Pahredaar-IoT AI Detection Architecture

      
    

    

      
How Incoming Network Flows Are Processed:

      
    
        
  1. Frontline Gate (Random Forest): Distinguishes benign background IoT chatter from attack patterns with high throughput (>900 flows/sec).
    2. 
        
  2. Open-Set Zero-Day Rejection: Analyzes high-dimensional feature geometry and ECDF calibration. Flows that deviate significantly from known attack centroids are triaged as UNKNOWN_SUSPICIOUS (Zero-Day threats).
    3. 
        
  3. Temporal Sequence Intelligence (LSTM): Tracks per-device multi-step reconnaissance and slow C2 beacons over rolling time windows.
    4. 
        
  4. Communication Graph Intelligence: Builds a dynamic device graph to detect lateral movement sweeps between compromised IoT nodes.
    5. 
        
  5. Non-Dilutive Hierarchical Risk Scoring: Combines all signals: \(R = w_f R_{flow} + w_n R_{novelty} + w_t R_{temporal} + w_g R_{graph}\) to assign robust device risk tiers (Low, Medium, High, Critical).
    6. 
      

      

        TreeSHAP Explainability: For every alert, exact Shapley values calculate how much each network feature pushed the prediction toward malicious (Red bars) or benign (Blue bars), ensuring full transparency for security auditors.
