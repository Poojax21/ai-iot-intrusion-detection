## 1. Executive Summary

Moving beyond synthetic flows, Component C validated the ingestion of real network traffic generated by **Zeek (formerly Bro)** network security monitors. 
The production adapter (`simulator/zeek_adapter.py`) was overhauled to handle real-world deployment challenges:
- Dynamic schema discovery via Zeek's `#fields` directive.
- Support for both traditional tab-separated values (TSV) and modern structured JSON-lines (`conn.log`).
- Dual runtime operational modes: **Live Tailing** (`--tail`) for active SPAN/mirror ports, and **Offline Replay** (`--replay`) for historical forensic PCAPs.
- Stateful UID deduplication cache to prevent alert flooding during network reconnections or log rotation.
- Resilient recovery from log truncation and hourly rotation without process termination.
- Zero-loss FIFO backpressure buffer to decouple network line rates from backend inference.

## 3. Operational Resilience Features

### 3.1 Dynamic Header Parsing
Zeek deployments frequently modify logging policies, reordering fields or appending custom attributes (e.g. `community_id`, `vlan`). `ZeekLogProcessor` intercepts `#fields` at stream startup and dynamically builds a column index, preventing field misalignment crashes.

### 3.2 Duplicate Record Suppression
When Zeek rotates logs or when a disconnected sensor reconnects, connection records may be re-read. `ZeekLogProcessor` tracks a bounded circular cache of seen connection UIDs (`seen_uids: deque(maxlen=50000)`). Re-transmitted UIDs are discarded before reaching model scoring or database persistence.

### 3.3 Log Rotation & File Truncation Recovery
In 24/7 network monitoring, Zeek rotates `conn.log` periodically (e.g., hourly). `follow_file()` tracks the underlying file inode and byte offset:
- If the file inode changes (log rotated to archive), the adapter smoothly reopens the newly created active file.
- If the file size drops below the current file pointer (file truncated), it automatically resets to offset 0 without throwing an EOF error.

### 3.4 Bounded Backpressure Buffering
If the backend undergoes maintenance or database lock contention, the adapter buffers up to $5,000$ flow records in memory. Under sustained saturation, it applies an **oldest-first drop policy** to protect edge gateway RAM while continuing to monitor real-time traffic.
